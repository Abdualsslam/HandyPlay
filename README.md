# HandyPlay

HandyPlay is a web-based gaming playground that uses computer vision and hand gestures (powered by MediaPipe) to let you play without touching a keyboard or mouse!

## Features & Games
- **Single-player Modes:**
  - 🎨 **Drawing:** Draw freely using your index finger in the air.
  - 🍉 **Fruit Ninja:** Slice incoming fruits with your hand movements.
  - 🎯 **Target Shooter:** Aim and shoot at targets using hand gestures.
  - 🤖 **AI Draw:** Draw shapes and let an AI try to guess them.
  
- **Multiplayer Modes:**
  - ❌⭕ **Tic-Tac-Toe:** Play a classic game of Tic-Tac-Toe using gestures.
  - 🖼️ **Pictionary:** A multiplayer drawing and guessing game.
  - 🎸 **Airband:** Make music by moving your hands like you're playing virtual instruments.

## Technologies Used
- HTML5 / CSS3 / JavaScript (Vanilla)
- [MediaPipe Hands](https://google.github.io/mediapipe/solutions/hands) for real-time hand tracking.

## How to Run
Simply open `index.html` in a modern web browser and grant the website permission to use your webcam. Ensure you are in a well-lit environment for the best hand-tracking performance.
